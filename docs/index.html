USB EspressLRS Sim Receiver Configurator

Web configurator for a USB ELRS/CRSF simulator receiver. The real-time view uses data streamed over USB Serial by the firmware. GitHub repository

Real-time Axes

HID Buttons

Active buttons are logical buttons. If a logical button has a keyboard key assigned, firmware sends the key instead of the joystick button.

Calibration

First capture the stick center. Then start travel calibration and move all sticks to their full minimum and maximum positions.

Log

Button Mapping

Each HID logical button can be activated by any CRSF channel in LOW, MID, or HIGH position. The keyboard column captures the key by pressing it on your keyboard.
